## Apache-2.0 obligations

If you redistribute Aarhus — modified or not — you must:

1. ship a copy of the Apache-2.0 licence (`LICENSE`),
2. keep the `NOTICE` file (or reproduce its content) so the modification record
   travels with the code,
3. state significant changes if you modify the theme further,
4. keep the licence and notice headers of third-party files intact.

Zendesk's own trademark and brand assets are **not** covered by the licence.
Aarhus ships no Zendesk logos: `settings/logo.png`, `settings/favicon.png` and
the background artwork are generated by `build/artwork.py` from the Aarhus
palette.

## Third-party licences inside the bundles

`assets/shared-bundle.js` and `assets/wysiwyg-bundle.js` embed dependencies.
`rollup.config.mjs` passes `format.comments: /@license|@preserve|^!/` to terser,
so the banners survive minification:

| Library | Licence |
| --- | --- |
| DOMPurify | Apache-2.0 or MPL-2.0 |
| regenerator-runtime | MIT |
| CKEditor 5 (via `@zendesk/help-center-wysiwyg`) | GPL-2.0-or-later |
| Zendesk Garden | Apache-2.0 |
| React / React DOM | MIT |

The `@zendesk/help-center-wysiwyg` build is licensed for use in Zendesk Help
Center only — see the `LICENSE.md` shipped inside that package.

## Adding new files

- New files written from scratch: no header needed, they fall under MIT.
- New files adapted from Copenhagen: add a short `/* Adapted from the Copenhagen
  theme (Apache-2.0, Copyright Zendesk, Inc.) */` header and extend `NOTICE`.
- Never copy Zendesk trademarks, logos or marketing copy into the theme.
